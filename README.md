# Lanyard support

This is the public issue tracker for **Lanyard**, the macOS profile manager for Claude Code by Nexus Systems. The app's source code is not here; this repository holds bug reports, feature requests and questions only.

## How to get help

- **From the app**: Settings → Support (or Help → Report a Problem). Lanyard shows you the exact text it will file, with paths, emails and tokens already removed, and then opens a prefilled issue here. Reports filed that way carry the `from-app` label.
- **By hand**: [open an issue](https://github.com/NX-System/lanyard-support/issues/new/choose) and pick a template.
- **By email**: support@nxsysdev.com, if you would rather not post publicly.
- **Security problems**: do not open an issue. See [SECURITY.md](SECURITY.md).

## Before you file

1. Update to the latest build from [lanyard.nxsys.app](https://lanyard.nxsys.app) and check whether the problem is still there.
2. Search the open issues; add a comment to an existing one instead of opening a duplicate.
3. Anything you paste is public. Lanyard's Support page redacts its own diagnostics, but check what you add yourself.

## Labels

`bug`, `feature-request`, `question` say what the issue is. `from-app` marks reports filed by Lanyard. `needs-info`, `confirmed`, `fixed-in-next`, `duplicate` and `wontfix` show where it stands.

Downloads and release notes: [github.com/NX-System/lanyard-releases](https://github.com/NX-System/lanyard-releases).
